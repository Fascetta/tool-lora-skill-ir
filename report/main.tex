\begin{abstract}
A tool-use skill maps a user request and prior observations to a structured tool call. We study whether demonstrations of such a skill can be replaced by a persistent intermediate representation that remains sufficient for execution after the demonstrations are deleted. We call this representation \emph{Skill IR}. Skill IR stores request-to-output relations and a lexical sidecar for opaque identifiers; it stores neither demonstrations nor adapter parameters. A deterministic resolver maps Skill IR to a frozen compiler, which creates a temporary LoRA adapter for a frozen language model. On an immutable 72-case controlled benchmark, the learned correspondence model P6-R1 retains the ground-truth permutation in every case and identifies it uniquely in 95.83\% of cases. An exact matcher identifies the ground-truth permutation uniquely in every case when all components are observable. In contrast, direct LoRA generation reaches 79.36\% correct-tool accuracy, below nearest-neighbor adapter retrieval at 94.31\%. These results establish execution-sufficient persistence in the controlled domain, but not recovery of the evaluator's predefined semantic factors.
\end{abstract}

\section{Introduction}

Low-rank adaptation (LoRA) modifies a frozen model weight matrix $W_0$ as $W=W_0+BA$, where $W$ is the adapted weight matrix, $A$ and $B$ are trainable low-rank matrices, and $BA$ is the effective weight update \cite{hu2022lora}. Here, \emph{frozen} means that a parameter is not updated during training. A \emph{hypernetwork}, defined as a neural network that generates parameters for another network, can generate $A$ and $B$ from a task description \cite{charakorn2025text}. This approach is attractive for tool use because one hypernetwork could specialize a language model for many tools.

However, LoRA parameters are not unique semantic identifiers. Let $R$ be any invertible matrix with dimensions compatible with $A$ and $B$. Then $(BR)(R^{-1}A)=BA$; therefore, different factor pairs implement the same update. Independently trained adapters may also implement similar behavior while occupying different parameter regions. Our experiments consequently distinguish two objects. \emph{Skill IR} is the persistent representation learned from demonstrations. The \emph{execution adapter} is the temporary LoRA adapter used by the frozen language model. Only Skill IR is treated as the persistent representation.

The research question is whether learner-visible demonstrations can produce one deterministic Skill IR that remains executable after demonstration deletion, without providing the learner with the evaluator's predefined semantic factor names. Code and frozen results are available at \url{https://github.com/Fascetta/tool-lora-skill-ir}.

\section{Method}

Let $\mathcal{D}$ denote the support set, i.e., the demonstrations available during acquisition. The maintained pipeline is
\begin{center}
\small
$\mathcal{D}\!\rightarrow\!\text{relations}\!\rightarrow\!\text{correspondence}$\\
$\rightarrow\!\text{Skill IR}\!\rightarrow\!\text{resolver}\!\rightarrow\!\text{compiler}$.
\end{center}

\paragraph{Relation acquisition.}
The system extracts observable relations between request fields and tool-call fields. An \emph{exact} relation copies a value, an \emph{enumerated} relation binds a request value to an opaque literal, and a \emph{transformed} relation reorders structured components.

\paragraph{Correspondence.}
P6-R1 is a frozen correspondence model with 13,281 parameters. It encodes source and target byte strings with a bidirectional gated recurrent unit and scores each source--target component pair. A one-to-one assignment selects a permutation $\pi$, where $j$ denotes a target position and $\pi(j)$ denotes the source position assigned to it. Thus, $\text{target}[j]=\text{source}[\pi(j)]$. The \emph{exact matcher} is a deterministic method that enumerates permutations and returns the unique permutation consistent with the observed target.

\paragraph{Skill IR and execution.}
\emph{Canonicalization} combines correspondence evidence from multiple demonstrations into one deterministic result using evidence count, assignment score, and confidence margin; the confidence margin is the difference between the best and second-best assignment scores. The resulting Skill IR stores relational records and a \emph{lexical sidecar}, defined as a table of opaque API names and literals. Skill IR excludes $\mathcal{D}$. After $\mathcal{D}$ is deleted, the \emph{resolver} deterministically maps Skill IR to fields expected by the frozen compiler. The compiler creates an \emph{execution adapter}, defined as the temporary LoRA adapter applied to the frozen language model, Qwen3-0.6B \cite{yang2025qwen3}.

\section{Experimental protocol}

The immutable benchmark contains 24 skill groups and three conditions per group. The \emph{matched} condition uses the same skill configuration during acquisition and evaluation. The \emph{alternate} condition changes examples while preserving the skill. The \emph{counterfactual} condition changes the component transformation. This design yields 72 cases.

We report four metrics. The \emph{ground-truth permutation} is the permutation specified by the benchmark. \emph{Any correct} means that the predicted set contains the ground-truth permutation. \emph{Unique correct} means that the ground-truth permutation is the only member of the predicted set. \emph{Reload} measures exact Skill-IR preservation after serialization. \emph{Time/case} is mean central-processing-unit latency in the recorded run. The \emph{deterministic acquisition control} extracts observable relations directly without using P6-R1.

\section{Results}

Table~\ref{tab:components} shows that every method retains a correct correspondence and preserves Skill IR exactly across reload. P6-R1 leaves three cases ambiguous. The exact matcher removes these ambiguities, but assumes that every source component occurs visibly in the target. Hence, it is a restricted method rather than a general replacement for P6-R1.

The adapter-generation study provides the motivating negative result. The strongest generated execution adapter obtains 79.36\% correct-tool accuracy, defined as the fraction of calls that name the required tool. Nearest-neighbor adapter retrieval, which reuses the adapter of the most similar training tool, obtains 94.31\%. An independently trained adapter for each evaluated tool obtains 99.34\%. Output-norm regularization, explicit singular-value generation, and a control that fixes $A$ while generating $B$ do not close this gap. Prior work also reports that $A$ and $B$ have different optimization roles \cite{zhu2024asymmetry}. In our setting, the result supports treating adapter parameters as execution state rather than Skill IR.

\section{Discussion and conclusion}

The experiment establishes an information-sufficiency result: in the controlled protocol domain, $\mathcal{D}$ contains enough information to construct a canonical Skill IR that preserves relational structure and opaque lexical identity, survives deletion of $\mathcal{D}$, and reconnects to the frozen execution pipeline.

The claim is intentionally limited. A \emph{semantic ontology} is the evaluator's predefined decomposition of a skill into named semantic factors. The learner does not receive these names, but the results do not show that it independently discovers the same decomposition. Additional intervention experiments produce stable statistical groups without independently controllable or compositional factors. Future evaluation should therefore use real demonstrations with opaque correspondences and should avoid using independently optimized LoRA parameters as semantic targets.
