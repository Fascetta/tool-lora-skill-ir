\begin{abstract}
We investigate whether demonstrations of a tool-use skill can be replaced by a persistent representation that remains executable after the demonstrations are deleted. We first study low-rank adaptation (LoRA) parameters as the representation. Generated adapters reach 79.36\% correct-tool accuracy, below nearest-neighbor adapter retrieval at 94.31\%. Multi-seed and free-latent controls show that the limitation is not explained solely by semantic conditioning: independently trained adapters are not unique parameter targets, while shared generators fit training behavior but generalize poorly. We therefore introduce \emph{Skill IR}, a serialized intermediate representation of request-to-action relations, operation effects, and opaque lexical identifiers. On a controlled 72-case benchmark, a learned correspondence model retains the correct transformation in every case and identifies it uniquely in 95.83\%. Skill IR also reconnects to evaluated AppWorld tools when operation effects disambiguate public schemas. However, learned effect acquisition remains sensitive to schema wording. The project thus establishes controlled execution-sufficient persistence while identifying adapter non-identifiability and schema shortcuts as distinct barriers to general tool-skill acquisition.
\end{abstract}

\section{Introduction}

A \emph{tool-use skill} is a rule that maps a user request and observable environment state to a structured tool call. A \emph{support set} is the set of demonstrations available while that rule is learned. Our question is whether a support set can be replaced by a persistent object that remains sufficient for execution after the support set is deleted.

We evaluate two candidate objects. An \emph{execution adapter} is a temporary LoRA applied to a language model. \emph{Skill IR} is a serialized intermediate representation learned from the support set. Skill IR, rather than the execution adapter, is the final persistent object.

LoRA modifies a frozen weight matrix $W_0$ as $W=W_0+BA$, where $W$ is the adapted matrix and $A$ and $B$ are trainable low-rank matrices \cite{hu2022lora}. Hypernetworks can generate these matrices from task descriptions \cite{charakorn2025text}. However, for any compatible invertible matrix $R$, $(BR)(R^{-1}A)=BA$. Thus, the factors are non-unique even when the effective update $BA$ is fixed. This ambiguity motivates our progression from generated execution adapters to structured Skill IR. Code and frozen results are available at \url{https://github.com/Fascetta/tool-lora-skill-ir}.

\section{Experimental progression}

The inherited evaluation framework provides a 15-tool comparison: nearest-neighbor adapter retrieval reuses the adapter associated with the most similar training tool, whereas a per-tool adapter is trained directly for each evaluation tool. We then isolate the failure. First, an \emph{adapter-identifiability audit} trains multiple adapters for the same tool. These adapters preserve tool identity while their effective updates remain weakly aligned; therefore, one independently trained update is not a unique semantic target. Second, a \emph{free-latent generator} replaces semantic input with one learned vector per training tool. It fits training behavior but remains below the per-tool validation ceiling, locating the dominant error after semantic encoding. Third, output-norm regularization, functional distillation, explicit singular-value generation, fixed-$A$/generated-$B$, and data-diversity controls do not reliably close the gap. The fixed-$A$/generated-$B$ control keeps $A$ constant and generates only $B$, reducing factor non-identifiability. These results reject generated adapter parameters as the persistent representation in the tested setting.

\paragraph{Controlled Skill IR.}
Skill IR stores three field types: \emph{relations} specify how request values determine tool-call values; an \emph{effect anchor} records whether an operation preserves or changes environment state; and a \emph{lexical sidecar} stores opaque API names and literals. During acquisition, correspondence evidence from the support set is canonicalized into one deterministic Skill IR. The support set is then deleted, Skill IR is serialized and reloaded, and a deterministic resolver maps it to a tool call.

The frozen correspondence model P6-R1 has 13,281 parameters. It encodes source and target byte strings, scores every source--target component pair, and predicts a one-to-one permutation. An \emph{exact matcher} enumerates permutations and applies only when every source component remains observable in the target.

The controlled benchmark contains 24 skill groups under matched, alternate, and counterfactual conditions, yielding 72 cases. \emph{Any} means that the prediction set contains the benchmark permutation; \emph{unique} means that this permutation is the only prediction; \emph{reload} means exact preservation after serialization.

P6-R1 retains the correct permutation in all cases and returns it uniquely in 69 of 72. The exact and rule-based controls solve all cases, showing that the controlled benchmark exposes sufficient observable structure for symbolic inference. The result establishes persistence and information sufficiency, not discovery of an evaluator-defined semantic decomposition.

\paragraph{AppWorld transfer.}
We next transfer Skill IR to public tool schemas derived from AppWorld. Oracle Skill IR and deterministic acquisition obtain 100\% matched and counterfactual action, argument-binding, and state accuracy on the evaluated Todoist fixtures. Learned correspondence also passes the predefined controls across three random seeds after correcting an evaluator coordinate convention.

Testing previously excluded Simple Note tools exposes a new failure. Two public APIs are structurally compatible with the same abstract action roles, so the generic resolver has 0\% mapping accuracy despite perfect representation serialization. We call this \emph{resolver-interface non-identifiability}: the resolver input does not contain enough information to select one mapping. Adding the effect anchor makes the mapping unique and restores 100\% matched and counterfactual execution in the evaluated fixtures.

Finally, we train an effect predictor from requests, public schemas, calls, results, and state transitions. It reaches 100\% synthetic training accuracy but fails on held-out concrete schemas. Deconfounded training restores 100\% matched execution for seeds 17, 29, and 43. Nevertheless, the latest intervention audit shows that semantic schema wording still influences predictions. We therefore classify the final learned-acquisition result as a \emph{residual schema shortcut}, rather than zero-shot schema invariance.

\section{Conclusion}

The complete project supports a conditional conclusion. Generated LoRA parameters are neither uniquely identifiable semantic targets nor a competitive persistent representation in our experiments. Skill IR succeeds when observable demonstrations identify the relations, effects, and lexical values required for execution: it survives support-set deletion and reconnects to controlled and selected AppWorld tools. The remaining problem is acquisition, not serialization or execution. Future work should evaluate effect learning under paraphrased and implicit schemas, missing observations, and genuinely unseen applications, while retaining causal interventions that distinguish semantic evidence from schema shortcuts.
